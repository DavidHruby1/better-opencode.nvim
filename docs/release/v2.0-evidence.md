[issue #26929](https://github.com/anomalyco/opencode/issues/26929); proposed
[PR #37541](https://github.com/anomalyco/opencode/pull/37541), commit
`61e0f0321e34e8134bc27ddf534b75933b9ceb38`, replaces the wire-format `Schema.Class` declarations with
`Schema.Struct`. No result artifact is recorded when this happens.

On 31 July 2026, diagnostic source builds of both exact commits with that upstream change produced a valid
`StructuredOutput`, exposed it through `info.structured`, and completed a real authenticated Build against
`openai/gpt-5.4`. These runs confirm the upstream root cause but are not release evidence: they are modified binaries,
and the `1.17.3` patch also changes the frozen `/doc` fingerprint. The release remains blocked until an official fixed
OpenCode version is audited and pinned.
